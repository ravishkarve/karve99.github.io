Autoresearch: options strategy agent

Modelled on Andrej Karpathy's autoresearch loop. An agent reads a plain-English research program and the log of past experiments, then proposes one change to a strategy config. A fixed harness backtests it. The change is kept only if it beats the best score so far, and the loop repeats until you stop it. A test period the agent never sees shows whether the gains are real or overfit.

1 Read program + results log→ 2 Propose one experiment→ 3 Backtest (fixed harness)→ 4 Score on train + validation→ 5 Keep if better, else discard↺

Setup

1. Data

Daily data with a date column, a close column and optionally vix or iv (for example NIFTY closes plus India VIX). Missing IV is estimated from 21-day realised volatility × 1.1.

Downloads NIFTY 50 daily closes and India VIX through the local bridge from the Live page. Kite history needs the paid Kite Connect plan and a Kite login on the Live page. Start the bridge with python3 options/bridge/sensibull_bridge.py.

2. Research program (program.md)

3. Proposer

A hill-climbing mutation search that changes one or two knobs of the best config at a time, with occasional random restarts. Runs entirely in your browser.

The browser calls the Anthropic API directly with your key. Use a key with a spend limit, and don't use this on a shared computer. Each experiment is one API call. The loop stops at the spend cap.

Read before trusting a result. Options are priced by the Black–Scholes model with a fixed volatility skew, using the day's implied volatility. They are not real historical option quotes. Fills happen at daily closes with modelled slippage and charges, and margin is approximate. The synthetic market builds in a volatility premium, which is exactly what makes option-selling profitable there. Set it to 0% to see what happens without it. Searching hundreds of variants will overfit. Trust a strategy only if its test result, which the agent never sees, holds up.

Research tool only, not investment advice. Past or simulated performance does not predict future results.

Abstract

MISES is the standard viscous–inviscid method for blade-to-blade analysis of turbomachinery cascades. This report describes pymises, a new implementation of the same class of analysis in Python, written from the published formulations rather than ported from the Fortran. Two inviscid solvers are provided: a periodic linear-vorticity panel method with a Karman–Tsien compressibility correction, and a finite-volume Euler solver on a periodic H-grid with Jameson–Schmidt–Turkel dissipation and streamtube-thickness (AVDR) terms. Both are coupled to Drela's two-equation integral boundary layer with eN transition and a lag-entrainment turbulence model. The panel path solves the boundary layer and its interaction with the inviscid flow simultaneously by Newton's method, using the exact source-influence matrix of the panel method. The Euler path couples through wall transpiration. Losses come from a compressible mixed-out control-volume analysis. The package ([[N_LINES]] lines) runs from TOML, JSON or YAML configuration files and a command line, reads MISES and Selig/Lednicer blade files, and is covered by [[N_TESTS]] unit tests. A verification suite of [[VER_N]] cases against exact solutions, classical boundary-layer results and conservation laws passes in full; the panel method converges at second order. A precomputed library of [[LIB_TOTAL]] operating points converges in [[LIB_CONV]] cases ([[LIB_PCT]] %), with failures confined to near-stall points. A web dashboard hosted on GitHub Pages runs the unmodified Python solver in the browser through WebAssembly. Every statement about the code in this report links to the line it describes. Two defects found while writing it are reported in Section 12.

Keywords: cascade aerodynamics; viscous–inviscid interaction; panel method; integral boundary layer; eN transition; Euler equations; mixed-out loss; code verification; Pyodide

1Introduction

Cascade analysis predicts how a two-dimensional section of a compressor or turbine blade row turns and decelerates the flow, and how much total pressure it loses. MISES [1, 2] solves this problem by coupling the steady Euler equations, discretised on an intrinsic streamline grid and solved by a global Newton method, to an integral boundary layer with eN transition [3]. The boundary-layer formulation is shared with XFOIL [4]. MISES is fast and well validated, but it is Fortran, distributed under licence, and driven by fixed-format input files, which makes it awkward to script, test or put in front of a browser.

The work described here set out to provide the same analysis as a readable Python package with four properties: it can be run from a configuration file; it carries unit tests and a verification suite; it has an online dashboard; and it is hosted where it can be inspected. The formulation follows the published papers and the XFOIL closure relations. The numerical methods for the inviscid flow differ from MISES, as summarised below.

  • Inviscid flow. MISES solves the Euler equations on a streamline grid with Newton's method. pymises offers a periodic panel method with a Karman–Tsien correction (Section 3) and a time-marching finite-volume Euler solver (Section 6).
  • Coupling. The panel path uses a simultaneous Newton solution like MISES and XFOIL (Section 5). The Euler path uses wall transpiration with the panel-method interaction matrix as an approximate Jacobian.
  • Loss. Both paths report the MISES mixed-out loss and exit angle (Section 7).

Section 8 describes the software, configuration and hosting; Section 9 the verification; Section 10 representative results; Section 11 the problems met during development; and Section 12 the limitations, including two defects found while preparing this report.

2Geometry and conventions

Coordinates follow MISES. The axial direction is x, the pitchwise direction y, and flow and metal angles are measured from axial, positive towards +y. A blade contour is stored counter-clockwise, starting at the trailing edge, running over the upper surface to the leading edge and back along the lower surface. The Blade class ([[geo_blade]]) enforces this on construction by removing repeated points and reversing clockwise input ([[geo_post_init]]). The leading edge is the point of the contour farthest from the trailing-edge midpoint, located on a cubic spline through the points ([[geo_le]]); the chord and stagger angle follow from it.

Blades come from four sources. The parametric generator ([[geo_from_parameters]]) lays a NACA 65-series, NACA 4-digit or British C4 thickness distribution ([[geo_half_thickness]]) over a circular-arc or quadratic Bézier camber line defined by the inlet and exit metal angles. MISES blade.xxx files are read directly ([[geo_read_mises]]). Selig and Lednicer aerofoil files are placed in the cascade at a given stagger and pitch (Section 8.3). Arbitrary coordinates can be given in a configuration file.

Before analysis the contour is repanelled ([[geo_repanel]]). Each surface uses the distribution

\begin{equation} s(t) = S\left[a\,\frac{1-\cos\pi t}{2} + (1-a)\sin\frac{\pi t}{2}\right], \qquad 0 \le t \le 1, \label{eq:repanel} \end{equation}

with t = 0 at the trailing edge and a = 0.3 by default. This clusters panels quadratically at the leading edge while keeping trailing-edge panels longer than a typical trailing-edge gap. The default is 180 panels. Blunt trailing edges are closed by blending the last 8 % of chord towards the trailing-edge midpoint with the smoothstep weight w = τ²(3 − 2τ) ([[geo_closed_te]]). The original thickness is not lost: it enters the loss analysis as base blockage (Section 7).

3Periodic panel method

3.1Kernel

The blade surface carries a vortex sheet whose strength γ varies linearly between nodes; γ equals the tangential surface speed. The stream function of an infinite row of unit vortices with pitch s at z0 = x0 + iy0 is

\begin{equation} \psi(z) = -\frac{1}{2\pi}\ln\left|\frac{s}{\pi}\sinh\frac{\pi (z - z_0)}{s}\right|. \label{eq:kernel} \end{equation}

The kernel is split into an isolated part and a smooth periodic remainder,

\begin{equation} \ln\left|\frac{s}{\pi}\sinh w\right| = \ln\left|z - z_0\right| + \ln\left|\frac{\sinh w}{w}\right|, \qquad w = \frac{\pi (z - z_0)}{s}. \label{eq:split} \end{equation}

The isolated part is integrated analytically over a linear-strength panel, giving the integrals of ln r and t ln r ([[pan_iso]]). The remainder is smooth and is integrated with four-point Gauss–Legendre quadrature per panel ([[pan_vcoef]]). It is evaluated by a series for |w| < 1 and an exponential form otherwise, which stays accurate far up- and downstream ([[pan_logsinh]]). Constant-strength source panels are treated the same way: analytic logarithm and arctangent terms for the isolated panel plus a periodic remainder built from coth w − 1/w ([[pan_srcvel]], [[pan_cothinv]]).

3.2Linear system

The unknowns are the N nodal values γj, the surface stream function Ψ0, and the pitchwise component vm of the vector-mean velocity. The stream function is enforced at every node,

\begin{equation} \sum_{j} A_{ij}\,\gamma_j + u_1 y_i - v_m x_i - \Psi_0 = 0, \qquad i = 1,\dots,N, \label{eq:colloc} \end{equation}

where u1 is the axial velocity. The Kutta condition and the prescribed inlet angle close the system:

\begin{equation} \gamma_1 + \gamma_N = 0, \qquad v_1 = v_m - \frac{\Gamma}{2s}, \qquad v_2 = v_m + \frac{\Gamma}{2s}, \label{eq:kutta} \end{equation}

with Γ the circulation per blade, computed from γ by the trapezoidal rule. The matrix is assembled and LU-factorised once per blade ([[pan_assemble]]). For a closed trailing edge the first and last nodes coincide and their collocation equations are identical, so the last row is replaced by equal second differences of γ at both ends ([[pan_closedrow]]). Two basis solutions, for unit axial and unit pitchwise inlet velocity, are stored, so a new inlet angle costs one superposition ([[pan_solve]]). The exit state follows from mass conservation including any source flux Q ([[pan_package]]):

\begin{equation} u_2 = u_1 + \frac{Q + \sigma_{\mathrm{TE}}\,h_{\mathrm{TE}}}{s}, \qquad \beta_2 = \arctan\frac{v_2}{u_2}. \label{eq:exit} \end{equation}

3.3Trailing edge

For a blunt trailing edge of gap hTE, the XFOIL treatment is implemented: a panel across the gap carries a constant vortex and source sheet equal to the components of the mean trailing-edge velocity along the bisector ([[pan_tegap]]). In practice this left a velocity oscillation at the trailing edge, which is why the solvers use the geometrically closed contour of Section 2.

3.4Source panels and the interaction matrix

The displacement effect of the boundary layer is represented by source panels. The source strength on panel k is the streamwise derivative of the mass defect m = ueδ*, taken in the direction of the local surface flow, so that σ = Gm ([[pan_G]]). The stream function of the source sheet is imposed on the inner side of the contour, where it is obtained by integrating the normal flux from the first node ([[pan_innerpsi]]); the blade interior therefore stays at rest. Because the system is linear, the response of γ to unit source strengths is precomputed with the same LU factors, and the interaction matrix

\begin{equation} \mathbf{D} = \frac{\partial u_e}{\partial m} = \operatorname{diag}(\pm 1)\,\frac{\partial \gamma}{\partial \sigma}\,\mathbf{G} \label{eq:D} \end{equation}

follows directly ([[pan_D]]). The sign converts signed γ to the edge speed on each surface. This matrix is what makes the simultaneous coupling of Section 5 possible.

3.5Compressibility

The panel solution is incompressible. Compressibility is added with the Karman–Tsien rule [9] in its hodograph velocity form ([[sol_kt]]):

\begin{equation} \frac{q_c}{V_1} = \frac{q_i\,(1-\lambda)}{1 - \lambda\,q_i^2}, \qquad \lambda = \frac{M_1^2}{\left(1 + \sqrt{1 - M_1^2}\right)^2}, \label{eq:kt} \end{equation}

where qi is the incompressible speed divided by V1. The map is exact at stagnation and at the inlet state, is smooth and monotone, and has an analytic derivative, which the Newton coupling needs. The more common pressure-coefficient form was tried first and abandoned because it had to be clipped at high local speed. The rule is only valid while the surface flow stays subsonic, and the solver warns when the peak isentropic Mach number exceeds one ([[sol_mis_warn]]).

4Integral boundary layer

4.1Variables and closures

Each station carries three primary variables: the amplification exponent ñ (laminar) or the root shear-stress coefficient Cτ1/2 (turbulent), the momentum thickness θ, and the mass defect m = ueδ*. Secondary quantities are evaluated in one vectorised routine ([[bl_station]]). The closures are those of XFOIL: the kinematic shape factor Hk of Whitfield [19] ([[bl_hkin]]); the laminar and turbulent energy shape factors H* ([[bl_hslam]], [[bl_hsturb]]); laminar skin friction from Falkner–Skan profiles and turbulent skin friction from Swafford's profiles [18] ([[bl_cflam]], [[bl_cfturb]]); the laminar dissipation ([[bl_dilam]]); and the density shape factor H** ([[bl_hc]]). Edge Mach number and Reynolds number include compressibility, with viscosity from Sutherland's law ([[bl_env]], [[gas_sutherland]]). The lag-equation constants are XFOIL's ([[bl_consts]]).

4.2Discrete equations

Between stations 1 and 2 the equations are written in XFOIL's logarithmic two-point form ([[bl_core]]). Bars denote interval averages. The momentum equation ([[bl_mom]]) is

\begin{equation} \ln\frac{\theta_2}{\theta_1} + \left(\bar H + 2 - \bar M_e^2\right)\ln\frac{u_{e2}}{u_{e1}} - \frac12\,\overline{C_f\,\frac{\xi}{\theta}}\,\ln\frac{\xi_2}{\xi_1} = 0, \label{eq:mom} \end{equation}

and the kinetic-energy shape-parameter equation ([[bl_shape]]) is

\begin{equation} \ln\frac{H^*_2}{H^*_1} + \left(\frac{2\bar H^{**}}{\bar H^{*}} + 1 - \bar H\right)\ln\frac{u_{e2}}{u_{e1}} + \left(\frac12\,\overline{C_f\,\frac{\xi}{\theta}} - \overline{\frac{2C_D}{H^*}\,\frac{\xi}{\theta}}\right)\ln\frac{\xi_2}{\xi_1} = 0. \label{eq:shape} \end{equation}

The third equation is the amplification equation in laminar flow ([[bl_lam]]),

\begin{equation} \tilde n_2 - \tilde n_1 - \overline{\frac{\mathrm{d}\tilde n}{\mathrm{d}\xi}}\,(\xi_2 - \xi_1) = 0, \label{eq:ampl} \end{equation}

with the envelope rate of Drela and Giles [3] ([[bl_ampl]]), and the lag equation in turbulent flow ([[bl_lag]]),

\begin{equation} K_C\left(\bar C_{\tau,\mathrm{EQ}}^{1/2} - \bar C_{\tau}^{1/2}\right)\Delta\xi - 2\bar\delta\,\ln\frac{C_{\tau 2}^{1/2}}{C_{\tau 1}^{1/2}} + 2\bar\delta\left(\bar u_q\,\Delta\xi - \ln\frac{u_{e2}}{u_{e1}}\right) = 0. \label{eq:lag} \end{equation}

The dissipation and lag terms use an upwinded average whose weight depends on the change of Hk across the interval ([[bl_upw]]), which keeps the scheme stable through separation.

4.3Transition

Transition occurs where ñ reaches Ncrit (default 9), or at a forced location. Placing transition at a station boundary makes the solution jump as the point crosses a station, and this was one source of non-convergence. The transition interval is therefore split at the interpolated transition point ([[bl_trpoint]]),

\begin{equation} f = \frac{N_{\mathrm{crit}} - \tilde n_1}{\left(\mathrm{d}\tilde n/\mathrm{d}\xi\right)_1\,\Delta\xi}, \qquad C_{\tau}^{1/2}\Big|_{\mathrm{tr}} = C_{\mathrm{TR}}\,e^{-C_{\mathrm{TREX}}/(H_k - 1)}\,C_{\tau,\mathrm{EQ}}^{1/2}, \label{eq:tr} \end{equation}

with a laminar sub-interval up to the transition point and a turbulent one after it; their residuals are summed ([[bl_split]]). The interval types are laminar, transition, turbulent, and frozen for a closed trailing edge ([[bl_intres]]).

4.4Stagnation point and marching

The surfaces start at the stagnation point of the inviscid solution ([[bl_surfaces]]). The first station is a similarity station with ue ∝ ξ, the Hiemenz condition ([[bl_sim]]). When the stagnation point lies within a quarter panel of a node, that node becomes a stagnation node with zero mass defect and no boundary-layer station ([[bl_stagnode]]); otherwise the first station has ue ≈ 0 and the Newton iteration fails. The displacement effect moves the stagnation point slightly, so ξ is re-anchored at every iteration to keep ue ∝ ξ at the first station ([[bl_xieff]]).

A station-by-station march ([[bl_march]]) provides the initial guess and solves flat-plate cases. Each station is solved by a bounded Newton iteration with a finite-difference Jacobian evaluated in one vectorised call ([[bl_newton]]). If the direct solution fails or Hk exceeds 3.8 (laminar) or 2.5 (turbulent), the station is solved in inverse mode with a prescribed Hk and free edge speed ([[bl_inverse]]).

5Viscous–inviscid coupling

5.1Interaction law and Newton system

For the panel path the edge speed at every node is a linear function of all mass defects, mapped through the Karman–Tsien rule F of equation \(\eqref{eq:kt}\):

\begin{equation} u_e = F\!\left(u_e^{0} + \mathbf{D}\,(m - m_{\mathrm{ref}})\right). \label{eq:law} \end{equation}

The discrete boundary-layer equations of both surfaces, three per station, are solved together with equation \(\eqref{eq:law}\) by Newton's method ([[bl_coupled]]). The Jacobian has a local part, from the derivatives of each interval residual with respect to the two stations' variables, and a dense global part through the interaction matrix ([[bl_assemble]], [[bl_chain]]):

\begin{equation} \mathbf{J} = \left.\frac{\partial \mathbf{R}}{\partial \mathbf{X}}\right|_{u_e} + \frac{\partial \mathbf{R}}{\partial u_e}\,\operatorname{diag}(F')\,\mathbf{D}\,\frac{\partial m}{\partial \mathbf{X}}. \label{eq:jac} \end{equation}

The local derivatives are taken by finite differences of the vectorised residual routine ([[bl_jac]]). With 180 panels the system has about 540 unknowns and is solved directly.

5.2Globalisation

Three devices make the iteration robust.

  • Initial guess. Each surface is marched with the inviscid edge speed, then improved by two quasi-simultaneous sweeps in the manner of Veldman [7], in which each station sees its own mass defect through the diagonal of D while all others are frozen ([[bl_qs]]).
  • Step limits. The Newton step is scaled so that θ, m and Cτ1/2 change by no more than +150 % or −50 %, and ñ by no more than 2 ([[bl_relax]]).
  • Line search. The step is halved up to eight times until the residual norm falls below 1.2 times its previous value ([[bl_linesearch]]).

The iteration stops when the largest relative change of θ and m is below 10−6 with a full step and no transition move, or after 80 iterations.

5.3Moving the transition point

Transition moves by at most one station per iteration, and only once the current solution has nearly converged: the largest relative change must be below 2 × 10−3 with a full step ([[bl_gate]]). Without this gate, transition drifted downstream one station per iteration while the rest of the solution was still changing. An upstream move switches the station to turbulent with the initial shear stress of equation \(\eqref{eq:tr}\); a downstream move re-marches the laminar equations until ñ reaches Ncrit, laminar separation occurs, or the forced-transition station is reached ([[bl_updtr]], [[bl_advlam]]). If transition moves by more than two stations the turbulent part is re-marched as well ([[bl_remarch]]). A location that has been visited before indicates a limit cycle, and transition is then frozen ([[bl_cycle]]).

5.4Closed trailing edge and output

At a closed trailing edge the last node of each surface coincides with the other surface's last node. These nodes are removed from the unknowns, and their columns of D are added to their neighbours', which ties their mass defect to the adjacent node ([[sol_closete]]). After convergence the displacement-corrected inviscid solution is recomputed with the converged sources, converted to incompressible units ([[sol_minc]]), and the surface isentropic Mach number is taken from it. The complete panel path is in [[sol_panel]].

6Euler solver

6.1Equations and grid

The Euler solver ([[eu_residual]]) integrates the conservation laws for a streamtube of thickness b(x), which reproduces MISES' axial-velocity-density-ratio capability:

\begin{equation} \frac{\partial}{\partial t}\int_{\Omega} b\,\mathbf{U}\,\mathrm{d}A + \oint_{\partial\Omega} b\,\mathbf{F}\cdot\mathbf{n}\,\mathrm{d}\ell = \int_{\Omega} p\,\nabla b\,\mathrm{d}A, \qquad \mathbf{U} = \left(\rho,\ \rho u,\ \rho v,\ \rho E\right)^{\mathsf T}. \label{eq:euler} \end{equation}

The pressure source is evaluated from the b-weighted face vectors, so a uniform flow in a channel of constant b is preserved exactly ([[eu_src]]). The grid is a periodic H-grid for one passage ([[eu_grid]]). Axial lines are cosine-clustered over the blade and stretched geometrically over 0.8 axial chords upstream and 1.2 downstream. The passage walls follow the blade surfaces, with the trailing edge sharpened over the last 4 % of chord ([[geo_axial]]), and continue as periodic lines along the inlet angle and the panel-predicted exit angle. Grid lines are clustered towards the walls and smoothed ([[eu_wallcluster]], [[eu_smoothgrid]]). The streamtube thickness is 1 upstream and falls linearly to 1/AVDR at the trailing edge.

6.2Discretisation

Fluxes are central, cell-centred averages ([[eu_flux]]). The artificial dissipation is the scalar scheme of Jameson, Schmidt and Turkel [5], applied to W = (ρ, ρu, ρv, ρH) so that it does not disturb a uniform total enthalpy:

\begin{equation} \mathbf{d}_{i+1/2} = \lambda_{i+1/2}\left[\varepsilon^{(2)}\,\Delta\mathbf{W} - \varepsilon^{(4)}\,\Delta^{3}\mathbf{W}\right], \qquad \varepsilon^{(2)} = k_2\,\nu\,\mu_M, \qquad \varepsilon^{(4)} = \max\!\left(0,\ k_4 - \varepsilon^{(2)}\right). \label{eq:jst} \end{equation}

Here ν is the pressure sensor and μM a switch that rises from 0 at a local Mach number of 0.85 to 1 at 1.0, which keeps the second-difference term away from smooth subsonic regions ([[eu_switch]]). At walls the dissipation stencil uses linear extrapolation instead of the mirror cells ([[eu_walldiss]]). Time marching uses four Runge–Kutta stages with coefficients ¼, ⅓, ½ and 1, local time steps at CFL 3.5, and implicit residual smoothing 𝒮 with Martinelli's variable coefficients [6] ([[eu_step]], [[eu_irs]]):

\begin{equation} \mathbf{U}^{(k)} = \mathbf{U}^{(0)} - \alpha_k\,\mathcal{S}\!\left[\frac{\Delta t}{V}\,\mathbf{R}\!\left(\mathbf{U}^{(k-1)}\right)\right]. \label{eq:rk} \end{equation}

The tridiagonal smoothing systems are solved in batches with LAPACK dgtsv ([[eu_thomas]]). Two safeguards follow each step: cells whose update would give near-zero density or pressure keep their previous state ([[eu_positivity]]), and the energy is reset so that the total enthalpy is uniform, which is exact for steady adiabatic flow and removes the slowest-converging mode ([[eu_iso]]).

6.3Boundary conditions and Mach-number control

Upstream and downstream of the blade the lower and upper boundaries are periodic; along the blade they are slip walls imposed by mirror ghost cells ([[eu_ghosts]]). The inlet fixes total pressure, total enthalpy and flow angle and extrapolates the outgoing Riemann invariant ([[eu_inlet]]). The exit fixes static pressure and extrapolates entropy, tangential velocity and the incoming invariant ([[eu_exit]]). As in MISES the user specifies the inlet Mach number, so a controller adjusts the exit pressure every 300 steps. Its gain halves whenever the error changes sign, and each correction is limited to 3 % of p0 ([[eu_ctrl]]). The run starts from a back pressure corresponding to 85 % of the estimated exit Mach number, so the inlet Mach number is approached from below ([[eu_init_bp]]). If the inlet Mach number cannot be reached even at a low back pressure the cascade is choked, and the solver stops with an error that states the attainable value ([[eu_choke]]). Convergence requires the residual to fall by the tolerance, inlet and exit mass flows to agree within 2 × 10−4, and the inlet Mach number to be within 5 × 10−4 of the target ([[eu_run]]).

6.4Viscous coupling

The Euler path couples by transpiration ([[sol_cycles]]). In each cycle the wall speeds of the Euler solution are given to the boundary-layer Newton solver of Section 5, with the interaction matrix of a panel method built on the Euler wall contour serving as an approximate Jacobian. The resulting mass defect is turned into a wall mass flux ρV1Gm per panel ([[sol_transp]]), which enters the Euler wall fluxes carrying the local tangential momentum and total enthalpy ([[eu_transp]]). The Euler solution is then advanced 1000 steps. Transition is frozen from the third cycle ([[sol_freeze]]), the cycles stop when the mass defect changes by less than 0.3 %, and a final Euler pass converges the flow with the last displacement ([[sol_final]]).

7Loss analysis

MISES reports the loss of the mixed-out state: the uniform flow that carries the same mass, axial momentum, tangential momentum and energy across one pitch as the real exit flow [8]. Given the fluxes per pitch, the tangential velocity is v = fy/ṁ, and the axial velocity solves ([[lo_mixed]], [[lo_quad]])

\begin{equation} \frac{\gamma+1}{2\gamma}\,\dot m\,u^{2} - f_x\,u + \frac{\gamma-1}{\gamma}\,\dot m\left(h_0 - \frac{v^{2}}{2}\right) = 0, \label{eq:mix} \end{equation}

taking the subsonic root; a negative discriminant means the mixed-out state is choked. The loss coefficient is referred to the inlet dynamic head, and an exit-based form is reported as well:

\begin{equation} \omega = \frac{p_{01} - p_{02}}{p_{01} - p_1}. \label{eq:omega} \end{equation}

In the panel path the exit flow is modelled as a uniform edge flow at the displacement-corrected exit angle, carrying the inlet mass flow through the pitch reduced by the displacement thickness and the trailing-edge thickness, with the momentum deficit θ ([[lo_edge]], [[lo_cascade]], [[sol_panel_loss]]). The trailing-edge thickness acts as base blockage at the edge pressure. In the Euler path the loss is split in two ([[sol_omegainv]], [[sol_dvisc]]). The part generated inside the domain, by shocks and numerical dissipation, is the drop in mass-averaged total pressure from the inlet plane to the exit plane ([[eu_p0avg]]). The viscous part is the difference between the mixed-out states of the exit plane with and without the trailing-edge boundary-layer deficits. Lieblein and Roudebush's formula [8] is implemented for comparison ([[lo_lieblein]]); it is the first-order term of the exact incompressible mixing analysis used as the verification reference ([[ver_incloss]]).

8Software and hosting

8.1Package

The package is plain Python on NumPy and SciPy (Table 1). The entry point is CascadeSolver ([[sol_class]]), which takes a Blade, FlowConditions ([[sol_flow]]) and ViscousOptions ([[sol_visc]]) and returns a result with performance data, surface distributions, boundary-layer data and, for Euler runs, the Mach field ([[sol_perf]]). On import the package limits OpenBLAS to one thread ([[init_threads]]). Without this a single LU factorisation took 0.66 s on the development machine because of thread contention; with it the factorisation is about thirty times faster.

[[T_MODULES]]

8.2Configuration files and command line

A case is described by a TOML, JSON or YAML file with the sections [case], [geometry], [flow], [viscous], [panel], [euler], [sweep] and [output] ([[cfg_parse]], [[cfg_build_case]]). Unknown sections and keys are rejected with the list of valid ones ([[cfg_dataclass]], [[cfg_keys]]). A sweep varies one parameter over a range or a list of values ([[cfg_sweep]], [[cfg_run]]). The command line ([[cli_main]]) provides run, verify, blade and example; results are written as JSON, CSV tables and matplotlib plots ([[io_save]], [[io_plot]]).

pymises example compressor .         # write an example configuration
pymises run compressor.toml          # solve; JSON, CSV and PNG output
pymises verify -o report/            # run the verification suite
pymises blade case.toml -w foil.dat  # export the blade (MISES or Selig format)

8.3Aerofoil coordinates

Any aerofoil in Selig format (the UIUC database and XFOIL convention [17]) or Lednicer format can be placed in a cascade. The parser accepts a name line, comment lines, commas and tabs, detects the Lednicer header of point counts, and joins the two Lednicer surfaces into one contour ([[geo_parse]]). The section is then normalised to its chord line ([[geo_normalise]]), using the same spline leading edge as the Blade class ([[geo_spline_le]]), optionally mirrored, rotated counter-clockwise by the stagger angle and spaced at the given pitch or solidity ([[geo_from_airfoil]], [[geo_from_selig]]). A contour that does not start and end at the trailing edge is rejected with a message rather than silently turned round. In configuration files the geometry type selig takes either a file or the coordinates inline ([[cfg_selig]]), and any blade can be exported as Selig coordinates ([[geo_to_selig]], [[cli_blade]]).

8.4Dashboard and hosting

The dashboard is one HTML file with hand-written SVG charts ([[ix_linechart]], [[ix_cascade]]). It has tabs for analysis of one operating point, loss buckets, Euler Mach fields, the verification report, configuration files and the Python source. It loads three precomputed data files ([[ix_boot]]), generated by a script that runs the panel library in four processes and the Euler cases in parallel ([[pre_panel]], [[pre_euler]]).

When the page is served from GitHub Pages, a Web Worker loads Pyodide 0.29.3 [14] with NumPy, SciPy and PyYAML, fetches the pymises sources, and runs the unmodified package ([[wk_init]]). The dashboard calls a small JSON interface ([[web_run]], [[web_compact]]) and receives progress messages during long runs. If the runtime cannot load, the page falls back to the precomputed library and records the reason in the status tooltip and console ([[ix_gooffline]], [[ix_startworker]]). For aerofoil input the browser parses and places the coordinates itself, mirroring the Python code, so the cascade preview updates while typing ([[ix_parse]], [[ix_place]]); the solve is done by Python. The generated configuration embeds the coordinates as a TOML multi-line literal string ([[ix_toml]]).

Hosting exposed one deployment problem. GitHub Pages builds sites with Jekyll, which does not publish files whose names begin with an underscore. pymises/__init__.py was therefore missing from the site, the import failed, and the dashboard stayed in library mode. The repository now has a .nojekyll file at its root, and the worker stops with an explicit message when a module file cannot be fetched ([[wk_fetchcheck]]). The worker also copies the example data files into the in-browser file system so file-based examples run ([[wk_data]]).

8.5Tests

The test suite has [[N_TESTS]] tests covering every module, the configuration runner and the command line. Four tests that run full Euler solutions take several minutes and are enabled with --runslow ([[test_conftest]]). Among the aerofoil tests, one checks that Selig and Lednicer versions of a section give the same blade ([[test_lednicer]]) and one that coarse and fine files give the same result ([[test_selig]]).

9Verification

Verification asks whether the equations are solved correctly [10]. Table 2 lists the suite ([[ver_run]]); every case compares pymises with an exact solution, a classical result or a conservation law. The transition case is strictly a validation, since the eN method is empirical; it is included to show that the transition Reynolds number is of the right size.

Manufactured cascade. No exact solution exists for flow through an arbitrary cascade, so one was manufactured ([[ver_mms]]). A uniform stream is combined with periodic rows of a source, a sink and a vortex. The closed streamline through the two stagnation points is an exact blade: the flow outside it is an exact cascade flow, and the Kutta condition holds at the rear stagnation point. For a general choice of strengths the two stagnation points do not lie on the same streamline, so the pitchwise free-stream component is solved for by root finding until they do ([[ver_close]]). The body is traced with a fourth-order Runge–Kutta integration of the velocity field and projected back onto the dividing streamline ([[ver_body]]). [[FIG:fig-mms]] compares the surface speed, and [[FIG:fig-conv]] shows second-order convergence.

[[F_MMS]] [[F_CONV]]

Isolated aerofoil. With a pitch of 104 chords the periodic kernel reduces to the isolated one, and a cambered Joukowski aerofoil provides an exact surface speed and lift ([[ver_jouk]]).

Boundary layer. The laminar march is compared with the Blasius solution and the similarity station with the Hiemenz stagnation-point solution [11] ([[ver_blas]], [[ver_hiem]]). The turbulent flat plate is compared with the Coles–Fernholz skin-friction relation [13] ([[ver_turb]]), and the transition Reynolds number with Michel's criterion [12] ([[ver_tr]]). [[FIG:fig-bl]] shows two of these.

[[F_BL]]

Loss. The compressible mixing routine is checked against the exact incompressible mixing analysis at low Mach number, and against conservation of mass, momentum and energy ([[ver_mix]], [[ver_cons]]).

Euler solver. Three cases are used. A uniform flow on a deliberately skewed grid must remain uniform to round-off ([[ver_fs]]). A quasi-one-dimensional Laval nozzle, modelled through the streamtube thickness, is solved with a normal shock ([[ver_noz]], [[FIG:fig-noz]]). Finally, the Euler and panel solvers are compared at M1 = 0.2, where compressibility is small ([[ver_evp]], [[FIG:fig-evp]]). This case is run with tolerances ten times tighter than the default ([[ver_tight]]), so that the reported spurious loss belongs to the scheme and not to incomplete convergence.

11Development record

Most of the effort went into robustness rather than the equations. Table 6 lists the problems in the order they were met, with the location of each fix. Three lessons stand out. First, the simultaneous Newton coupling failed through a chain of separate causes, and each fix exposed the next: the stagnation station, the compressibility map, the closed trailing edge, and several transition effects. Second, verification caught real errors, such as the scaling of the periodic source integral and a round-off sign flip, and it also confirmed features that looked wrong but were right, such as the leading-edge suction peak. Third, the Euler solver needed a sequence of standard safeguards before it ran reliably across compressor, transonic and turbine cases.

12Limitations and known defects

Two defects were found while the data for this report were checked. They are recorded here and have not been fixed.

Defect 1 · Euler convergence test with transpirationThe mass-balance convergence test compares inlet and exit mass flows directly ([[eu_masscheck]]). With viscous coupling the wall transpiration adds the displacement mass flow, so the two can never agree. The final Euler pass of every viscous case therefore runs to the step limit of 8000 without being reported as unconverged. Table 4 shows that the stored mass differences of 2.1–4.6 % match the estimated injected mass, so the flow solutions themselves are consistent. The cost is run time. The fix is to subtract the total transpiration flux from the balance.
Defect 2 · Euler loss split for the turbineFor the turbine case the viscous increment ([[sol_dvisc]]) is negative ([[EU_TURB_VISC]]), and the inviscid part is [[EU_TURB_INV]]. The total Euler loss of [[EU_TURB_OM]] cannot be compared reliably with the panel value of [[PAN_TURB_OM]]. Two causes contribute. For an accelerating cascade the exit dynamic head is about four times the inlet head used to normalise ω, so the scheme's spurious loss is magnified. And the viscous increment is a small difference of two mixed-out states whose core flow already contains the transpiration mass. Turbine loss levels from the Euler path should be treated as indicative.

The remaining limitations follow from the methods chosen.

  • Panel path. The Karman–Tsien rule is valid only while the surface flow is subsonic. Cases with a peak isentropic Mach number above one carry a warning, and the Euler path should be used for them.
  • Euler path. The algebraic H-grid gives a spurious loss of about 0.1–0.3 % of the inlet dynamic head. The default tolerance ([[eu_tol]]) adds up to 0.3 % more. Tightening the default made long viscous runs diverge, so tight tolerances are used only for inviscid runs. A viscous Euler case takes two to five minutes.
  • Boundary layer. There is no wake march: the loss is mixed out from trailing-edge integrals. Massive separation and stall are outside the model; 6 of the 111 library points do not fully converge.
  • Scope compared with MISES. There is no streamline-grid Newton Euler solver, no inverse design mode, no multi-element blades and no radius change beyond the streamtube thickness.
  • Browser solver. The in-browser runtime could not be exercised automatically in the development environment, which had no access to the Pyodide CDN. Its Python path was tested natively through the same JSON interface.

13Conclusions

pymises reproduces the structure of MISES-style cascade analysis in [[N_LINES]] lines of Python: two inviscid solvers, Drela's integral boundary layer with eN transition, simultaneous or transpiration coupling, and mixed-out losses. The panel path is verified to second order against a manufactured cascade solution, the boundary layer against classical solutions, and the Euler solver against a shocked nozzle flow and the panel method. The package runs from configuration files and a command line, accepts MISES and Selig/Lednicer geometry, and runs unchanged in a browser from a static web page. Its limitations are documented, and the two defects identified in Section 12 have clear fixes.

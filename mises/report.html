Abstract

MISES is the standard viscous–inviscid method for blade-to-blade analysis of turbomachinery cascades. This report describes pymises, a new implementation of the same class of analysis in Python, written from the published formulations rather than ported from the Fortran. Two inviscid solvers are provided: a periodic linear-vorticity panel method with a Karman–Tsien compressibility correction, and a finite-volume Euler solver on a periodic H-grid with Jameson–Schmidt–Turkel dissipation and streamtube-thickness (AVDR) terms. Both are coupled to Drela's two-equation integral boundary layer with eN transition and a lag-entrainment turbulence model. The panel path solves the boundary layer and its interaction with the inviscid flow simultaneously by Newton's method, using the exact source-influence matrix of the panel method. The Euler path couples through wall transpiration. Losses come from a compressible mixed-out control-volume analysis, and lift and drag coefficients from the same control volume. The package (5,723 lines) runs from TOML, JSON or YAML configuration files and a command line, reads MISES and Selig/Lednicer blade files, and is covered by 110 unit tests. A verification suite of 12 cases against exact solutions, classical boundary-layer results and conservation laws passes in full; the panel method converges at second order. A precomputed library of 195 operating points converges in 184 cases (94 %), with failures confined to near-stall points. A web dashboard hosted on GitHub Pages runs the unmodified Python solver in the browser through WebAssembly. Every statement about the code in this report links to the line it describes. Three defects found while preparing the report were fixed and are described in Sections 11 and 12, and Section 13 discusses how convergence can be improved further.

Keywords: cascade aerodynamics; viscous–inviscid interaction; panel method; integral boundary layer; eN transition; Euler equations; mixed-out loss; code verification; Pyodide

1Introduction

Cascade analysis predicts how a two-dimensional section of a compressor or turbine blade row turns and decelerates the flow, and how much total pressure it loses. MISES [1, 2] solves this problem by coupling the steady Euler equations, discretised on an intrinsic streamline grid and solved by a global Newton method, to an integral boundary layer with eN transition [3]. The boundary-layer formulation is shared with XFOIL [4]. MISES is fast and well validated, but it is Fortran, distributed under licence, and driven by fixed-format input files, which makes it awkward to script, test or put in front of a browser.

The work described here set out to provide the same analysis as a readable Python package with four properties: it can be run from a configuration file; it carries unit tests and a verification suite; it has an online dashboard; and it is hosted where it can be inspected. The formulation follows the published papers and the XFOIL closure relations. The numerical methods for the inviscid flow differ from MISES, as summarised below.

  • Inviscid flow. MISES solves the Euler equations on a streamline grid with Newton's method. pymises offers a periodic panel method with a Karman–Tsien correction (Section 3) and a time-marching finite-volume Euler solver (Section 6).
  • Coupling. The panel path uses a simultaneous Newton solution like MISES and XFOIL (Section 5). The Euler path uses wall transpiration with the panel-method interaction matrix as an approximate Jacobian.
  • Loss. Both paths report the MISES mixed-out loss and exit angle (Section 7).

Section 8 describes the software, configuration and hosting; Section 9 the verification; Section 10 representative results; Section 11 the problems met during development; and Section 12 the limitations, including two defects found while preparing this report.

2Geometry and conventions

Coordinates follow MISES. The axial direction is x, the pitchwise direction y, and flow and metal angles are measured from axial, positive towards +y. A blade contour is stored counter-clockwise, starting at the trailing edge, running over the upper surface to the leading edge and back along the lower surface. The Blade class (geometry.py:197) enforces this on construction by removing repeated points and reversing clockwise input (geometry.py:221). The leading edge is the point of the contour farthest from the trailing-edge midpoint, located on a cubic spline through the points (geometry.py:257); the chord and stagger angle follow from it.

Blades come from four sources. The parametric generator (geometry.py:420) lays a NACA 65-series, NACA 4-digit or British C4 thickness distribution (geometry.py:59) over a circular-arc or quadratic Bézier camber line defined by the inlet and exit metal angles. MISES blade.xxx files are read directly (geometry.py:588). Selig and Lednicer aerofoil files are placed in the cascade at a given stagger and pitch (Section 8.3). Arbitrary coordinates can be given in a configuration file.

Before analysis the contour is repanelled (geometry.py:346). Each surface uses the distribution

\begin{equation} s(t) = S\left[a\,\frac{1-\cos\pi t}{2} + (1-a)\sin\frac{\pi t}{2}\right], \qquad 0 \le t \le 1, \label{eq:repanel} \end{equation}

with t = 0 at the trailing edge and a = 0.3 by default. This clusters panels quadratically at the leading edge while keeping trailing-edge panels longer than a typical trailing-edge gap. The default is 180 panels. Blunt trailing edges are closed by blending the last 8 % of chord towards the trailing-edge midpoint with the smoothstep weight w = τ²(3 − 2τ) (geometry.py:374–404). The original thickness is not lost: it enters the loss analysis as base blockage (Section 7).

3Periodic panel method

3.1Kernel

The blade surface carries a vortex sheet whose strength γ varies linearly between nodes; γ equals the tangential surface speed. The stream function of an infinite row of unit vortices with pitch s at z0 = x0 + iy0 is

\begin{equation} \psi(z) = -\frac{1}{2\pi}\ln\left|\frac{s}{\pi}\sinh\frac{\pi (z - z_0)}{s}\right|. \label{eq:kernel} \end{equation}

The kernel is split into an isolated part and a smooth periodic remainder,

\begin{equation} \ln\left|\frac{s}{\pi}\sinh w\right| = \ln\left|z - z_0\right| + \ln\left|\frac{\sinh w}{w}\right|, \qquad w = \frac{\pi (z - z_0)}{s}. \label{eq:split} \end{equation}

The isolated part is integrated analytically over a linear-strength panel, giving the integrals of ln r and t ln r (panel.py:79). The remainder is smooth and is integrated with four-point Gauss–Legendre quadrature per panel (panel.py:105). It is evaluated by a series for |w| < 1 and an exponential form otherwise, which stays accurate far up- and downstream (panel.py:45). Constant-strength source panels are treated the same way: analytic logarithm and arctangent terms for the isolated panel plus a periodic remainder built from coth w − 1/w (panel.py:134, panel.py:63).

3.2Linear system

The unknowns are the N nodal values γj, the surface stream function Ψ0, and the pitchwise component vm of the vector-mean velocity. The stream function is enforced at every node,

\begin{equation} \sum_{j} A_{ij}\,\gamma_j + u_1 y_i - v_m x_i - \Psi_0 = 0, \qquad i = 1,\dots,N, \label{eq:colloc} \end{equation}

where u1 is the axial velocity. The Kutta condition and the prescribed inlet angle close the system:

\begin{equation} \gamma_1 + \gamma_N = 0, \qquad v_1 = v_m - \frac{\Gamma}{2s}, \qquad v_2 = v_m + \frac{\Gamma}{2s}, \label{eq:kutta} \end{equation}

with Γ the circulation per blade, computed from γ by the trapezoidal rule. The matrix is assembled and LU-factorised once per blade (panel.py:280–294). For a closed trailing edge the first and last nodes coincide and their collocation equations are identical, so the last row is replaced by equal second differences of γ at both ends (panel.py:291). Two basis solutions, for unit axial and unit pitchwise inlet velocity, are stored, so a new inlet angle costs one superposition (panel.py:320). The exit state follows from mass conservation including any source flux Q (panel.py:335):

\begin{equation} u_2 = u_1 + \frac{Q + \sigma_{\mathrm{TE}}\,h_{\mathrm{TE}}}{s}, \qquad \beta_2 = \arctan\frac{v_2}{u_2}. \label{eq:exit} \end{equation}

3.3Trailing edge

For a blunt trailing edge of gap hTE, the XFOIL treatment is implemented: a panel across the gap carries a constant vortex and source sheet equal to the components of the mean trailing-edge velocity along the bisector (panel.py:248–275). In practice this left a velocity oscillation at the trailing edge, which is why the solvers use the geometrically closed contour of Section 2.

3.4Source panels and the interaction matrix

The displacement effect of the boundary layer is represented by source panels. The source strength on panel k is the streamwise derivative of the mass defect m = ueδ*, taken in the direction of the local surface flow, so that σ = Gm (panel.py:365). The stream function of the source sheet is imposed on the inner side of the contour, where it is obtained by integrating the normal flux from the first node (panel.py:239); the blade interior therefore stays at rest. Because the system is linear, the response of γ to unit source strengths is precomputed with the same LU factors, and the interaction matrix

\begin{equation} \mathbf{D} = \frac{\partial u_e}{\partial m} = \operatorname{diag}(\pm 1)\,\frac{\partial \gamma}{\partial \sigma}\,\mathbf{G} \label{eq:D} \end{equation}

follows directly (panel.py:382). The sign converts signed γ to the edge speed on each surface. This matrix is what makes the simultaneous coupling of Section 5 possible.

3.5Compressibility

The panel solution is incompressible. Compressibility is added with the Karman–Tsien rule [9] in its hodograph velocity form (solver.py:249):

\begin{equation} \frac{q_c}{V_1} = \frac{q_i\,(1-\lambda)}{1 - \lambda\,q_i^2}, \qquad \lambda = \frac{M_1^2}{\left(1 + \sqrt{1 - M_1^2}\right)^2}, \label{eq:kt} \end{equation}

where qi is the incompressible speed divided by V1. The map is exact at stagnation and at the inlet state, is smooth and monotone, and has an analytic derivative, which the Newton coupling needs. The more common pressure-coefficient form was tried first and abandoned because it had to be clipped at high local speed. The rule is only valid while the surface flow stays subsonic, and the solver warns when the peak isentropic Mach number exceeds one (solver.py:437).

4Integral boundary layer

4.1Variables and closures

Each station carries three primary variables: the amplification exponent ñ (laminar) or the root shear-stress coefficient Cτ1/2 (turbulent), the momentum thickness θ, and the mass defect m = ueδ*. Secondary quantities are evaluated in one vectorised routine (boundary_layer.py:187). The closures are those of XFOIL: the kinematic shape factor Hk of Whitfield [19] (boundary_layer.py:55); the laminar and turbulent energy shape factors H* (boundary_layer.py:64, boundary_layer.py:73); laminar skin friction from Falkner–Skan profiles and turbulent skin friction from Swafford's profiles [18] (boundary_layer.py:89, boundary_layer.py:97); the laminar dissipation (boundary_layer.py:108); and the density shape factor H** (boundary_layer.py:116). Edge Mach number and Reynolds number include compressibility, with viscosity from Sutherland's law (boundary_layer.py:147, gas.py:84). The lag-equation constants are XFOIL's (boundary_layer.py:36–46).

4.2Discrete equations

Between stations 1 and 2 the equations are written in XFOIL's logarithmic two-point form (boundary_layer.py:218). Bars denote interval averages. The momentum equation (boundary_layer.py:241) is

\begin{equation} \ln\frac{\theta_2}{\theta_1} + \left(\bar H + 2 - \bar M_e^2\right)\ln\frac{u_{e2}}{u_{e1}} - \frac12\,\overline{C_f\,\frac{\xi}{\theta}}\,\ln\frac{\xi_2}{\xi_1} = 0, \label{eq:mom} \end{equation}

and the kinetic-energy shape-parameter equation (boundary_layer.py:248) is

\begin{equation} \ln\frac{H^*_2}{H^*_1} + \left(\frac{2\bar H^{**}}{\bar H^{*}} + 1 - \bar H\right)\ln\frac{u_{e2}}{u_{e1}} + \left(\frac12\,\overline{C_f\,\frac{\xi}{\theta}} - \overline{\frac{2C_D}{H^*}\,\frac{\xi}{\theta}}\right)\ln\frac{\xi_2}{\xi_1} = 0. \label{eq:shape} \end{equation}

The third equation is the amplification equation in laminar flow (boundary_layer.py:256),

\begin{equation} \tilde n_2 - \tilde n_1 - \overline{\frac{\mathrm{d}\tilde n}{\mathrm{d}\xi}}\,(\xi_2 - \xi_1) = 0, \label{eq:ampl} \end{equation}

with the envelope rate of Drela and Giles [3] (boundary_layer.py:121), and the lag equation in turbulent flow (boundary_layer.py:270),

\begin{equation} K_C\left(\bar C_{\tau,\mathrm{EQ}}^{1/2} - \bar C_{\tau}^{1/2}\right)\Delta\xi - 2\bar\delta\,\ln\frac{C_{\tau 2}^{1/2}}{C_{\tau 1}^{1/2}} + 2\bar\delta\left(\bar u_q\,\Delta\xi - \ln\frac{u_{e2}}{u_{e1}}\right) = 0. \label{eq:lag} \end{equation}

The dissipation and lag terms use an upwinded average whose weight depends on the change of Hk across the interval (boundary_layer.py:230), which keeps the scheme stable through separation.

4.3Transition

Transition occurs where ñ reaches Ncrit (default 9), or at a forced location. Placing transition at a station boundary makes the solution jump as the point crosses a station, and this was one source of non-convergence. The transition interval is therefore split at the interpolated transition point (boundary_layer.py:281),

\begin{equation} f = \frac{N_{\mathrm{crit}} - \tilde n_1}{\left(\mathrm{d}\tilde n/\mathrm{d}\xi\right)_1\,\Delta\xi}, \qquad C_{\tau}^{1/2}\Big|_{\mathrm{tr}} = C_{\mathrm{TR}}\,e^{-C_{\mathrm{TREX}}/(H_k - 1)}\,C_{\tau,\mathrm{EQ}}^{1/2}, \label{eq:tr} \end{equation}

with a laminar sub-interval up to the transition point and a turbulent one after it; their residuals are summed (boundary_layer.py:330). The interval types are laminar, transition, turbulent, and frozen for a closed trailing edge (boundary_layer.py:308).

4.4Stagnation point and marching

The surfaces start at the stagnation point of the inviscid solution (boundary_layer.py:384). The first station is a similarity station with ue ∝ ξ, the Hiemenz condition (boundary_layer.py:342). When the stagnation point lies within a quarter panel of a node, that node becomes a stagnation node with zero mass defect and no boundary-layer station (boundary_layer.py:407); otherwise the first station has ue ≈ 0 and the Newton iteration fails. Nodes closer to the stagnation point than 0.05 % of chord are not stations either (boundary_layer.py:381, boundary_layer.py:432); Section 13 describes the failure that led to this rule. The displacement effect moves the stagnation point slightly, so ξ is re-anchored at every iteration to keep ue ∝ ξ at the first station (boundary_layer.py:513).

A station-by-station march (boundary_layer.py:530) provides the initial guess and solves flat-plate cases. Each station is solved by a bounded Newton iteration with a finite-difference Jacobian evaluated in one vectorised call (boundary_layer.py:1111). If the direct solution fails or Hk exceeds 3.8 (laminar) or 2.5 (turbulent), the station is solved in inverse mode with a prescribed Hk and free edge speed (boundary_layer.py:620).

5Viscous–inviscid coupling

5.1Interaction law and Newton system

For the panel path the edge speed at every node is a linear function of all mass defects, mapped through the Karman–Tsien rule F of equation \(\eqref{eq:kt}\):

\begin{equation} u_e = F\!\left(u_e^{0} + \mathbf{D}\,(m - m_{\mathrm{ref}})\right). \label{eq:law} \end{equation}

The discrete boundary-layer equations of both surfaces, three per station, are solved together with equation \(\eqref{eq:law}\) by Newton's method (boundary_layer.py:656). The Jacobian has a local part, from the derivatives of each interval residual with respect to the two stations' variables, and a dense global part through the interaction matrix (boundary_layer.py:830, boundary_layer.py:855):

\begin{equation} \mathbf{J} = \left.\frac{\partial \mathbf{R}}{\partial \mathbf{X}}\right|_{u_e} + \frac{\partial \mathbf{R}}{\partial u_e}\,\operatorname{diag}(F')\,\mathbf{D}\,\frac{\partial m}{\partial \mathbf{X}}. \label{eq:jac} \end{equation}

The local derivatives are taken by finite differences of the vectorised residual routine (boundary_layer.py:915). With 180 panels the system has about 540 unknowns and is solved directly.

5.2Globalisation

Three devices make the iteration robust.

  • Initial guess. Each surface is marched with the inviscid edge speed, then improved by two quasi-simultaneous sweeps in the manner of Veldman [7], in which each station sees its own mass defect through the diagonal of D while all others are frozen (boundary_layer.py:776).
  • Step limits. The Newton step is scaled so that θ, m and Cτ1/2 change by no more than +150 % or −50 %, and ñ by no more than 2 (boundary_layer.py:860).
  • Line search. The step is halved up to eight times until the residual norm falls below 1.2 times its previous value (boundary_layer.py:708).

The iteration stops when the largest relative change of θ and m is below 10−6 with a full step and no transition move, or after 80 iterations.

5.3Moving the transition point

Transition moves by at most one station per iteration, and only once the current solution has nearly converged: the largest relative change must be below 2 × 10−3 with a full step (boundary_layer.py:731). Without this gate, transition drifted downstream one station per iteration while the rest of the solution was still changing. An upstream move switches the station to turbulent with the initial shear stress of equation \(\eqref{eq:tr}\); a downstream move re-marches the laminar equations until ñ reaches Ncrit, laminar separation occurs, or the forced-transition station is reached (boundary_layer.py:969, boundary_layer.py:1000). If transition moves by more than two stations the turbulent part is re-marched as well (boundary_layer.py:1042). A location that has been visited before indicates a limit cycle, and transition is then frozen (boundary_layer.py:738).

5.4Closed trailing edge and output

At a closed trailing edge the last node of each surface coincides with the other surface's last node. These nodes are removed from the unknowns, and their columns of D are added to their neighbours', which ties their mass defect to the adjacent node (solver.py:654). After convergence the displacement-corrected inviscid solution is recomputed with the converged sources, converted to incompressible units (solver.py:416), and the surface isentropic Mach number is taken from it. The complete panel path is in solver.py:379.

6Euler solver

6.1Equations and grid

The Euler solver (euler.py:350) integrates the conservation laws for a streamtube of thickness b(x), which reproduces MISES' axial-velocity-density-ratio capability:

\begin{equation} \frac{\partial}{\partial t}\int_{\Omega} b\,\mathbf{U}\,\mathrm{d}A + \oint_{\partial\Omega} b\,\mathbf{F}\cdot\mathbf{n}\,\mathrm{d}\ell = \int_{\Omega} p\,\nabla b\,\mathrm{d}A, \qquad \mathbf{U} = \left(\rho,\ \rho u,\ \rho v,\ \rho E\right)^{\mathsf T}. \label{eq:euler} \end{equation}

The pressure source is evaluated from the b-weighted face vectors, so a uniform flow in a channel of constant b is preserved exactly (euler.py:130). The grid is a periodic H-grid for one passage (euler.py:143). Axial lines are cosine-clustered over the blade and stretched geometrically over 0.8 axial chords upstream and 1.2 downstream. The passage walls follow the blade surfaces, with the trailing edge sharpened over the last 4 % of chord (geometry.py:637), and continue as periodic lines along the inlet angle and the panel-predicted exit angle. Grid lines are clustered towards the walls and smoothed (euler.py:780, euler.py:753). The streamtube thickness is 1 upstream and falls linearly to 1/AVDR at the trailing edge. Figure 2 shows two of the grids.

6.2Discretisation

Fluxes are central, cell-centred averages (euler.py:431). The artificial dissipation is the scalar scheme of Jameson, Schmidt and Turkel [5], applied to W = (ρ, ρu, ρv, ρH) so that it does not disturb a uniform total enthalpy:

\begin{equation} \mathbf{d}_{i+1/2} = \lambda_{i+1/2}\left[\varepsilon^{(2)}\,\Delta\mathbf{W} - \varepsilon^{(4)}\,\Delta^{3}\mathbf{W}\right], \qquad \varepsilon^{(2)} = k_2\,\nu\,\mu_M, \qquad \varepsilon^{(4)} = \max\!\left(0,\ k_4 - \varepsilon^{(2)}\right). \label{eq:jst} \end{equation}

Here ν is the pressure sensor and μM a switch that rises from 0 at a local Mach number of 0.85 to 1 at 1.0, which keeps the second-difference term away from smooth subsonic regions (euler.py:374). At walls the dissipation stencil uses linear extrapolation instead of the mirror cells (euler.py:362). Time marching uses four Runge–Kutta stages with coefficients ¼, ⅓, ½ and 1, local time steps at CFL 3.5, and implicit residual smoothing 𝒮 with Martinelli's variable coefficients [6] (euler.py:481, euler.py:465):

\begin{equation} \mathbf{U}^{(k)} = \mathbf{U}^{(0)} - \alpha_k\,\mathcal{S}\!\left[\frac{\Delta t}{V}\,\mathbf{R}\!\left(\mathbf{U}^{(k-1)}\right)\right]. \label{eq:rk} \end{equation}

The tridiagonal smoothing systems are solved in batches with LAPACK dgtsv (euler.py:788). Two safeguards follow each step: cells whose update would give near-zero density or pressure keep their previous state (euler.py:494), and the energy is reset so that the total enthalpy is uniform, which is exact for steady adiabatic flow and removes the slowest-converging mode (euler.py:502).

6.3Boundary conditions and Mach-number control

Upstream and downstream of the blade the lower and upper boundaries are periodic; along the blade they are slip walls imposed by mirror ghost cells (euler.py:294). The inlet fixes total pressure, total enthalpy and flow angle and extrapolates the outgoing Riemann invariant (euler.py:317). The exit fixes static pressure and extrapolates entropy, tangential velocity and the incoming invariant (euler.py:333). As in MISES the user specifies the inlet Mach number, so a controller adjusts the exit pressure every 300 steps. Its gain halves whenever the error changes sign, and each correction is limited to 3 % of p0 (euler.py:549). The run starts from a back pressure corresponding to 85 % of the estimated exit Mach number, so the inlet Mach number is approached from below (euler.py:288). If the inlet Mach number cannot be reached even at a low back pressure the cascade is choked, and the solver stops with an error that states the attainable value (euler.py:562). Convergence requires three conditions (euler.py:521). The density residual must have fallen by the tolerance, measured from the start of the whole computation so that restarts are not asked for a further drop (euler.py:528). The exit mass flow must equal the inlet mass flow plus the mass injected by wall transpiration, within 2 × 10−4 (euler.py:573, euler.py:694). And the inlet Mach number must be within 5 × 10−4 of the target.

6.4Viscous coupling

The Euler path couples by transpiration (solver.py:492). In each cycle the wall speeds of the Euler solution are given to the boundary-layer Newton solver of Section 5, with the interaction matrix of a panel method built on the Euler wall contour serving as an approximate Jacobian. The resulting mass defect is turned into a wall mass flux ρV1Gm per panel (solver.py:527), which enters the Euler wall fluxes carrying the local tangential momentum and total enthalpy (euler.py:446). The Euler solution is then advanced 1000 steps. Over the last 4 % of chord the H-grid walls sharpen the trailing edge, which puts a spurious deceleration into the Euler wall speed; the boundary layer separates on it and its Newton iteration does not converge. Over that region the edge speed passed to the boundary layer therefore takes its shape from the panel solution of the real blade, scaled to the Euler speed where the sharpening starts (solver.py:631). Transition is frozen from the third cycle (solver.py:509), the cycles stop when the mass defect changes by less than 0.3 % and the boundary layer has converged (solver.py:530), and a final Euler pass converges the flow with the last displacement (solver.py:536); if it does not meet the convergence criteria the result carries a warning (solver.py:540).

7Loss analysis

MISES reports the loss of the mixed-out state: the uniform flow that carries the same mass, axial momentum, tangential momentum and energy across one pitch as the real exit flow [8]. Given the fluxes per pitch, the tangential velocity is v = fy/ṁ, and the axial velocity solves (losses.py:37, losses.py:45)

\begin{equation} \frac{\gamma+1}{2\gamma}\,\dot m\,u^{2} - f_x\,u + \frac{\gamma-1}{\gamma}\,\dot m\left(h_0 - \frac{v^{2}}{2}\right) = 0, \label{eq:mix} \end{equation}

taking the subsonic root; a negative discriminant means the mixed-out state is choked. The loss coefficient is referred to the inlet dynamic head, and an exit-based form is reported as well:

\begin{equation} \omega = \frac{p_{01} - p_{02}}{p_{01} - p_1}. \label{eq:omega} \end{equation}

In the panel path the exit flow is modelled as a uniform edge flow at the displacement-corrected exit angle, carrying the inlet mass flow through the pitch reduced by the displacement thickness and the trailing-edge thickness, with the momentum deficit θ (losses.py:78, losses.py:114, solver.py:432). The trailing-edge thickness acts as base blockage at the edge pressure. In the Euler path the exit-plane fluxes contain the displacement mass injected by transpiration. The real exit flow is obtained by subtracting the trailing-edge boundary-layer deficits from them, and it is mixed out. The total loss is measured from the inlet-plane mass-averaged total pressure to this mixed-out state (solver.py:601). It is split into the part generated inside the domain by shocks and numerical dissipation, the drop in mass-averaged total pressure from the inlet plane to the exit plane (solver.py:586, euler.py:684), and the remainder, which is the viscous and mixing loss. An earlier version measured the viscous part against a mixed-out core that still contained the transpiration mass; Section 12 describes why that failed. Lieblein and Roudebush's formula [8] is implemented for comparison (losses.py:161); it is the first-order term of the exact incompressible mixing analysis used as the verification reference (verification.py:446).

7.1Lift and drag

The same control volume gives the force on a blade (losses.py:172, solver.py:352). With the uniform inlet state, the mixed-out exit state and ṁ = ρ1u1s, the force per unit span is

\begin{equation} F_x = s\,(p_1 - p_2) + \dot m\,(u_1 - u_2), \qquad F_y = \dot m\,(v_1 - v_2). \label{eq:force} \end{equation}

Lift is its component normal to the vector-mean direction, normalised by the inlet dynamic pressure and the chord; the momentum drag is the component along it:

\begin{equation} \tan\beta_m = \tfrac12\left(\tan\beta_1 + \tan\beta_2\right), \qquad C_L = \frac{F_y\cos\beta_m - F_x\sin\beta_m}{\tfrac12\rho_1 V_1^2\,c}, \qquad C_{D,\mathrm{mom}} = \frac{F_x\cos\beta_m + F_y\sin\beta_m}{\tfrac12\rho_1 V_1^2\,c}. \label{eq:clcd} \end{equation}

In incompressible flow these reduce to the classical cascade relations D = sΔp0 cos βm and L = ρscx2(tan β1 − tan β2)/cos βm − sΔp0 sin βm [15]. In compressible flow the density change through the passage gives the momentum drag a part that does not vanish without loss; for a decelerating compressor cascade it is negative, and the first version of this code reported negative drag at M1 ≥ 0.65 for that reason. The reported drag coefficient is therefore the loss-based form, which equals the momentum drag in incompressible flow:

\begin{equation} C_D = \frac{s}{c}\,\frac{p_{01} - p_{02}}{\tfrac12\rho_1 V_1^2}\,\cos\beta_m. \label{eq:cd} \end{equation}

The momentum value is kept as a diagnostic. With an AVDR other than one the end-wall pressure force is not included, so the coefficients are approximate.

8Software and hosting

8.1Package

The package is plain Python on NumPy and SciPy (Table 1). The entry point is CascadeSolver (solver.py:220), which takes a Blade, FlowConditions (solver.py:50) and ViscousOptions (solver.py:82) and returns a result with performance data, surface distributions, boundary-layer data and, for Euler runs, the Mach field (solver.py:308). On import the package limits OpenBLAS to one thread (__init__.py:12). Without this a single LU factorisation took 0.66 s on the development machine because of thread contention; with it the factorisation is about thirty times faster.

8.2Configuration files and command line

A case is described by a TOML, JSON or YAML file with the sections [case], [geometry], [flow], [viscous], [panel], [euler], [sweep] and [output] (config.py:82, config.py:222). Unknown sections and keys are rejected with the list of valid ones (config.py:119, config.py:130). A sweep varies one parameter over a range or a list of values (config.py:258, config.py:285). The command line (cli.py:77) provides run, verify, blade and example; results are written as JSON, CSV tables and matplotlib plots (io.py:46, io.py:111).

pymises example compressor .         # write an example configuration
pymises run compressor.toml          # solve; JSON, CSV and PNG output
pymises verify -o report/            # run the verification suite
pymises blade case.toml -w foil.dat  # export the blade (MISES or Selig format)

8.3Aerofoil coordinates

Any aerofoil in Selig format (the UIUC database and XFOIL convention [17]) or Lednicer format can be placed in a cascade. The parser accepts a name line, comment lines, commas and tabs, detects the Lednicer header of point counts, and joins the two Lednicer surfaces into one contour (geometry.py:108). The section is then normalised to its chord line (geometry.py:167), using the same spline leading edge as the Blade class (geometry.py:182), optionally mirrored, rotated counter-clockwise by the stagger angle and spaced at the given pitch or solidity (geometry.py:532, geometry.py:563). A contour that does not start and end at the trailing edge is rejected with a message rather than silently turned round. In configuration files the geometry type selig takes either a file or the coordinates inline (config.py:171), and any blade can be exported as Selig coordinates (geometry.py:576, cli.py:52).

8.4Dashboard and hosting

The dashboard is one HTML file with hand-written SVG charts (index.html:485, index.html:551). It has tabs for analysis of one operating point, loss buckets, Euler Mach fields, the verification report, configuration files and the Python source. It loads three precomputed data files (index.html:1156), generated by a script that runs the panel library in four processes and the Euler cases in parallel (precompute.py:101, precompute.py:60).

When the page is served from GitHub Pages, a Web Worker loads Pyodide 0.29.3 [14] with NumPy, SciPy and PyYAML, fetches the pymises sources, and runs the unmodified package (worker.js:20). The dashboard calls a small JSON interface (webapi.py:92, webapi.py:48) and receives progress messages during long runs. If the runtime cannot load, the page falls back to the precomputed library and records the reason in the status tooltip and console (index.html:1095, index.html:1080). For aerofoil input the browser parses and places the coordinates itself, mirroring the Python code, so the cascade preview updates while typing (index.html:700, index.html:732); the solve is done by Python. The generated configuration embeds the coordinates as a TOML multi-line literal string (index.html:682). When the pasted section and its placement match the NACA 4412 library family, the precomputed results are shown without a solve (index.html:603).

The Euler tab draws the Mach field as filled cells with iso-Mach lines from a marching-squares routine and a bold sonic line, and can overlay or show only the computational mesh (index.html:949, index.html:937). In live mode two further runs are available: an incidence sweep of whatever geometry is set up on the Analyze tab, overlaid on the loss bucket with its lift and drag (index.html:864, index.html:827), and an Euler solution of that geometry, added to the list of Mach fields (index.html:911).

Hosting exposed one deployment problem. GitHub Pages builds sites with Jekyll, which does not publish files whose names begin with an underscore. pymises/__init__.py was therefore missing from the site, the import failed, and the dashboard stayed in library mode. The repository now has a .nojekyll file at its root, and the worker stops with an explicit message when a module file cannot be fetched (worker.js:31). The worker also copies the example data files into the in-browser file system so file-based examples run (worker.js:15).

8.5Tests

The test suite has 110 tests covering every module, the configuration runner and the command line. Four tests that run full Euler solutions take several minutes and are enabled with --runslow (conftest.py:14). Among the aerofoil tests, one checks that Selig and Lednicer versions of a section give the same blade (test_airfoil.py:41) and one that coarse and fine files give the same result (test_airfoil.py:134).

9Verification

Verification asks whether the equations are solved correctly [10]. Table 2 lists the suite (verification.py:668); every case compares pymises with an exact solution, a classical result or a conservation law. The transition case is strictly a validation, since the eN method is empirical; it is included to show that the transition Reynolds number is of the right size.

Manufactured cascade. No exact solution exists for flow through an arbitrary cascade, so one was manufactured (verification.py:70). A uniform stream is combined with periodic rows of a source, a sink and a vortex. The closed streamline through the two stagnation points is an exact blade: the flow outside it is an exact cascade flow, and the Kutta condition holds at the rear stagnation point. For a general choice of strengths the two stagnation points do not lie on the same streamline, so the pitchwise free-stream component is solved for by root finding until they do (verification.py:92). The body is traced with a fourth-order Runge–Kutta integration of the velocity field and projected back onto the dividing streamline (verification.py:154). Figure 3 compares the surface speed, and Figure 4 shows second-order convergence.

Isolated aerofoil. With a pitch of 104 chords the periodic kernel reduces to the isolated one, and a cambered Joukowski aerofoil provides an exact surface speed and lift (verification.py:309).

Boundary layer. The laminar march is compared with the Blasius solution and the similarity station with the Hiemenz stagnation-point solution [11] (verification.py:341, verification.py:366). The turbulent flat plate is compared with the Coles–Fernholz skin-friction relation [13] (verification.py:393), and the transition Reynolds number with Michel's criterion [12] (verification.py:418). Figure 5 shows two of these.

Loss. The compressible mixing routine is checked against the exact incompressible mixing analysis at low Mach number, and against conservation of mass, momentum and energy (verification.py:461, verification.py:485).

Lift and drag. Two unit tests check equation \(\eqref{eq:clcd}\). At M1 = 0.02 the coefficients reproduce the incompressible cascade relations to 0.2 % (test_losses.py:59). For an inviscid panel solution the momentum lift equals the Kutta–Joukowski lift from the circulation to 0.5 %, and the drag is zero to within 2 × 10−3 (test_losses.py:94).

Euler solver. Three cases are used. A uniform flow on a deliberately skewed grid must remain uniform to round-off (verification.py:505). A quasi-one-dimensional Laval nozzle, modelled through the streamtube thickness, is solved with a normal shock (verification.py:553, Figure 6). Finally, the Euler and panel solvers are compared at M1 = 0.2, where compressibility is small (verification.py:621, Figure 7). This case is run with tolerances ten times tighter than the default (verification.py:629), so that the reported spurious loss belongs to the scheme and not to incomplete convergence.

11Development record

Most of the effort went into robustness rather than the equations. Table 6 lists the problems in the order they were met, with the location of each fix. Three lessons stand out. First, the simultaneous Newton coupling failed through a chain of separate causes, and each fix exposed the next: the stagnation station, the compressibility map, the closed trailing edge, and several transition effects. Second, verification caught real errors, such as the scaling of the periodic source integral and a round-off sign flip, and it also confirmed features that looked wrong but were right, such as the leading-edge suction peak. Third, the Euler solver needed a sequence of standard safeguards before it ran reliably across compressor, transonic and turbine cases.

12Limitations and known defects

Three defects were found while the data for this report were checked. All three have been fixed.

Fixed · Euler convergence test with transpirationThe mass-balance test compared inlet and exit mass flows directly. With viscous coupling the wall transpiration adds the displacement mass flow, 2–5 % of the inlet flow, so the two never agreed, and the final Euler pass of every viscous case ran to the 8000-step limit without being reported. The test now subtracts the injected mass (euler.py:573, euler.py:694), the residual reference is kept from the start of the computation (euler.py:528), and an unconverged final pass produces a warning (solver.py:540). Table 4 shows the effect: the final passes now converge in 75–475 steps instead of 8000, and the remaining imbalance is below the 2 × 10−4 tolerance. Together with the coupling fixes below, the viscous compressor case at M1 = 0.5 now runs in about a third of the time.
Fixed · Euler loss split and viscous couplingThe turbine's viscous loss increment was negative. Tracing it uncovered three linked problems. First, the H-grid sharpens the trailing edge over the last 4 % of axial chord, which puts a false acceleration and then deceleration into the wall speed. The boundary layer separated on it, and its Newton iteration failed in most coupling cycles; the old test looked only at the last cycle, and a stalled iteration returns an unchanged mass defect that looked like convergence. The edge speed over that region is now a straight-line extrapolation of the preceding 8 % of chord (solver.py:631), and the cycles stop only on a converged boundary layer (solver.py:530). Second, the trailing-edge edge state used for the boundary-layer deficits was read from the same corrupted wall speeds, about 20 % too low; it now comes from the boundary layer's corrected edge speed (solver.py:552). Third, the loss is referred to the inlet-plane mass-averaged total pressure, and the viscous part is measured to the mixed-out real flow (solver.py:601). Table 8 shows the result: the viscous part of the Euler loss now matches the panel-method loss to about 10 % for the compressor and aerofoil cases.

The remaining limitations follow from the methods chosen.

  • Panel path. The Karman–Tsien rule is valid only while the surface flow is subsonic. Cases with a peak isentropic Mach number above one carry a warning, and the Euler path should be used for them.
  • Euler path. The algebraic H-grid gives a spurious loss of about 0.1–0.3 % of the inlet dynamic head for thin compressor blades and several per cent for thick, highly cambered ones. The default tolerance (euler.py:57) adds up to 0.3 % more; tight tolerances are used for inviscid runs. A viscous Euler case takes one to four minutes.
  • Boundary layer. There is no wake march: the loss is mixed out from trailing-edge integrals. Massive separation and stall are outside the model. The points that do not fully converge are at the highest or lowest incidence, where a leading-edge separation bubble forms or the surface flow becomes supersonic.
  • Lift and drag. They are defined for AVDR = 1; with a streamtube contraction the end-wall force is missing.
  • Scope compared with MISES. There is no streamline-grid Newton Euler solver, no inverse design mode, no multi-element blades and no radius change beyond the streamtube thickness.
  • Browser solver. The in-browser runtime could not be exercised automatically in the development environment, which had no access to the Pyodide CDN. Its Python path was tested natively through the same JSON interface.

13Improving convergence

A failure traced and fixed. The NACA 4412 family initially failed at β1 = 38° for every Mach and Reynolds number, although that point lies in the middle of its loss bucket. The Newton step shrank to zero in the line search while the residual stayed near 49, and the largest residuals were at the first three upper-surface stations. At this inlet angle the stagnation point lies on the shortest leading-edge panels, 72 % of the way along the panel that ends at the leading-edge node, just short of the 75 % threshold of the stagnation-node rule. Three stations then sat within 0.001 chord of the stagnation point with edge speeds between 0.001 and 0.09 V1, so the similarity station and the first two intervals were nearly singular. Stations closer than 0.05 % chord are now excluded (boundary_layer.py:381, boundary_layer.py:432). The case converges in 25 iterations, the loss is identical to four figures for thresholds between 0.02 % and 0.2 % chord, and other cases are unchanged. A regression test covers it (test_airfoil.py:154).

What the remaining failures have in common. The other points that do not fully converge are at the edges of the bucket. At high incidence the suction surface has a leading-edge laminar bubble, transition within the first 7 % of chord and often a trailing-edge separation; at low incidence and M1 = 0.65 the pressure side is locally supersonic. In both cases the line search collapses in the same way as above.

Proposals. The following ideas address these observations; none is implemented yet.

  1. Residual equilibration. In the failure above, a handful of stations near stagnation carried almost all of the residual norm, and the line search, which tests the unscaled norm (boundary_layer.py:708), rejected steps that improved the rest of the solution. Scaling each equation by a local reference (θ, H, ñ) and each unknown by its magnitude would make acceptance reflect the whole solution.
  2. Pseudo-transient continuation. When the line search collapses, adding a diagonal pseudo-time term to the Jacobian and shrinking it as the residual falls (switched evolution relaxation) keeps the iteration moving through separated regions where Newton's method alone stalls.
  3. A differentiable transition point. Transition moves by at most one station per iteration and only after the rest of the solution has settled (boundary_layer.py:731), which costs many iterations. Making the transition fraction of equation \(\eqref{eq:tr}\) a Newton unknown, with closures blended smoothly across the transition interval, would let transition move within the Newton step and restore quadratic convergence.
  4. Continuation along a sweep. Sweeps solve each point from a cold start. Interpolating the previous converged state onto the new stations (in ξ from the new stagnation point) would give an initial guess close to the answer; combined with pseudo-arclength continuation in incidence, the edge of the bucket would appear as a computed limit point (stall) rather than as non-convergence.
  5. Library-based initial guesses. The 184 converged library cases describe how θ, H and transition vary with incidence, Mach and Reynolds number for three blade types. An initial guess interpolated from the nearest library cases, in place of the uncoupled march and quasi-simultaneous sweeps (boundary_layer.py:776), costs nothing at run time and does not affect the converged answer.
  6. Analytic Jacobians. The interval Jacobians are finite differences (boundary_layer.py:915). Near separation the closures are stiff, and truncation error in the Jacobian degrades the Newton direction. Hand-derived derivatives, as in XFOIL, or automatic differentiation would remove that error.
  7. Anderson acceleration of the Euler coupling. The transpiration cycles (solver.py:492) are a fixed-point iteration on the mass-defect vector with a fixed relaxation. Anderson mixing over the last few cycles would reduce the number of cycles, each of which costs 1000 Euler steps.
  8. An analytic Mach-number controller. The exit-pressure controller (euler.py:549) uses a fixed gain with halving on overshoot. The mass-flow function gives dM1/dpexit in closed form for a choked or near-choked passage, which would allow a secant or Newton update and fewer control intervals.
  9. A body-fitted leading-edge grid. An O- or C-type block around the leading edge would remove the grid-independent spurious loss of the turbine (Table 7) and the associated slow convergence.

14Conclusions

pymises reproduces the structure of MISES-style cascade analysis in 5,723 lines of Python: two inviscid solvers, Drela's integral boundary layer with eN transition, simultaneous or transpiration coupling, and mixed-out losses. The panel path is verified to second order against a manufactured cascade solution, the boundary layer against classical solutions, and the Euler solver against a shocked nozzle flow and the panel method. The package runs from configuration files and a command line, accepts MISES and Selig/Lednicer geometry, and runs unchanged in a browser from a static web page. It reports mixed-out loss, exit angle and lift and drag coefficients. The three defects found while preparing this report have been fixed, its remaining limitations are documented, and Section 13 sets out how convergence can be improved further.

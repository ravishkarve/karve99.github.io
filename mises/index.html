Running pymises

        

          
Install

          
cd mises
pip install -e ".[plot,yaml,test]"

          
Command line

          
pymises example compressor .      # write an example config
pymises run compressor.toml       # solve, write JSON / CSV / PNG
pymises run compressor_sweep.toml # [sweep] section: loss bucket
pymises verify -o report/         # verification suite
pymises blade case.toml -w blade.c4   # export MISES blade file

          
Python

          
from pymises import Blade, FlowConditions, CascadeSolver

blade = Blade.from_parameters(inlet_metal_angle=45, exit_metal_angle=15,
                              max_thickness=0.08, thickness_form="c4", pitch=0.9)
flow = FlowConditions(inlet_mach=0.5, inlet_angle=43.0, reynolds=5e5)
result = CascadeSolver(blade, flow).solve()        # method="euler" for Euler
print(result.summary())
result.save("results/")

          
Config sections

          
[case] name, method (panel | euler), output_dir. [geometry] type = parametric, mises (a MISES blade.xxx file), naca4 or coordinates. [flow] inlet_mach, inlet_angle, reynolds, gamma, t01, avdr. [viscous] enabled, ncrit, xtr_upper, xtr_lower. [panel] and [euler] hold numerical settings; [sweep] takes a parameter such as flow.inlet_angle with values or start/stop/step. TOML, JSON and YAML are accepted; unknown keys are rejected with the list of valid ones.
